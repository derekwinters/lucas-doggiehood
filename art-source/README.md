# art-source — raw asset packs (staging, not imported)

Raw third-party asset packs live here **outside `Assets/`** on purpose: Unity only
imports files under `Assets/`, so staging them here keeps ~1,700 raw files (PNG, SVG,
vector sources, sample HTML, fonts) from being imported and generating `.meta`/GUID
churn before we've decided what we actually use.

Nothing here is referenced by the game yet. The build does not depend on this folder.

## Contents

### `kenney/ui-pack/` — Kenney "UI Pack" (CC0)
Rounded 9-slice panels, pill buttons, checkboxes/toggles, sliders, cursors — plus a
rounded TTF font and UI `.ogg` sounds. Candidate chrome for the Candy Cottage UI
(`docs/specs/world/art-style.md`), tinted to our bright palette rather than used as-is.

### `kenney/game-icons/` — Kenney "Game Icons" (CC0)
~225 flat white icons (gear, wrench/tools, close, checkmarks, arrows, …), tintable to
the ink color. Candidate icons for the settings/debug UI.

**License:** both packs are CC0 (public domain) — see each pack's `License.txt` /
`license.txt`. No attribution required.

### `blender/` — our own Blender models (source)
The generator scripts, exports, textures and approved review renders for the houses
(`blender/`), the textured trees (`blender/environment/trees/`) and the street props
(`blender/environment/street-props/`). These are Doggiehood's own models, generated by
Blender Python scripts, not a third-party pack, and the cleanup below does not apply to
them. How they are built and exported: `docs/engineering/blender-pipeline.md`.

### `splash/` — the splash art, rebuilt as layers (source)
The splash image (`Assets/Art/Splash/cover-art.png`) rebuilt as separate reusable
layers (#841). So far: the DOGGIEHOOD title as a layered vector SVG, a flat
screen-print version and 6000 px transparent PNGs, built by `splash/build_title.py`
from the Fredoka font (SIL OFL 1.1, licence in `splash/fonts/`); and the background and
environment (sky, sun, clouds, street, houses, trees, props) as full-frame vector layers,
built by `splash/build_scene.py`. Our own work, like
`blender/`; the cleanup below does not apply. Details: `splash/README.md`.
