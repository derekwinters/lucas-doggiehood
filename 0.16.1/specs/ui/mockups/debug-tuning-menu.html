Debug tuning menu

A debug-menu overlay exposing the Core TuningConfig (#620) balance values as labeled sliders, grouped into Pacing, Economy, Expansion and Move-in, so Derek can tune pacing live on-device. Reached from a new "Tune balance…" row in the Settings Debug tab; it layers as a centered modal over the open Settings panel. Styling is deliberately utilitarian — NOT the Candy Cottage art treatment — because it's a developer instrument. It ships in every build and is reached only through the existing 10-tap Debug unlock (#219, corrected by #656).

Shown 1:1 at the true 1920×1200 reference. Two states: (1) the Debug-tab entry row, (2) the tuning panel open. Values are representative placeholders from TuningConfig (#620).

Regions

Entry row ("Tune balance…", Settings Debug tab — behind the 10-tap unlock) · Scrim (dims Settings, modal) · Header (title + Reset all + ✕, pinned) · Scroll body (4 groups) · Group (name + Reset + control rows) · Control row (label + live value + slider).

Groups & tunables (from TuningConfig #620): Pacing — min target, max target, window, refresh · Economy — reward, paid markup, cost-tier gates ×2 · Expansion — tile/house/upgrade each base + step (2 sliders) · Move-in — early rate, late rate, population span.

base + step = two sliders. A linear base + step×n tunable is two adjacent rows (base, step), matching the #620 field shape.

Design decisions

① Entry point (Option A — Derek, 2026-08-06): a new "Tune balance…" action row in the existing Settings Debug tab — keeps the #219 "debug affordances live in the Debug tab" standard, adds a new "row opens a sub-panel" pattern.

② Panel vs Settings: the tuning panel layers over the still-open Settings panel as a centered modal (per the shared modal-overlay convention), it does not replace it; ✕ or scrim tap returns to the Debug tab.

③ Reset: both a global Reset all (header) and a per-group Reset — reset = re-seed from a fresh TuningConfig (#620).

④ Gating (corrected — Derek, #656): the entry row (and overlay) is built in every build and the existing 10-tap Debug unlock (#219) is its only gate. This reverses the original dev-build-only rule: the debug menu stays in the game on purpose while the balance is being dialed in, and the whole debug menu is removed later in one deliberate pass.

⑤ Style: deliberately NOT Candy Cottage — flat panel, thin outline, plain track/knob sliders, mono value readouts. It's a dev tool; the exemption is intentional.
