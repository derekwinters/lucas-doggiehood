Tab label swaps once per phase, not per step — all four tutorial steps show the same title. StepDotCount and the step-dots region are dropped entirely. Revised again (2026-07-31): the first fix hardcoded a fixed 112px bar height assuming a single-line message, but the tutorial step-1 message wraps to two lines at this width — its taller content pushed the vertically-centered text back up into the tab. Fix: when the phase-title tab is shown, the bar's height is no longer fixed — it sizes to its content (min-height 88px, same as today) plus PhaseTitleContentTopPaddingPx (48px, was 24px) above and the new PhaseTitleContentBottomPaddingPx (16px) below, so a wrapped 2-line message simply grows the bar taller instead of colliding with the tab. The bottom anchor (CoachBottomMarginPx) is unchanged; the bar still only grows upward.
