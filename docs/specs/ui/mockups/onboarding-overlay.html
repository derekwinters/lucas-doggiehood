Gesture-arrow coach constants (#330, @ 1200px ref)

ConstantValueApplies to
GestureCenterYPx480vertical anchor (x = center)
ArrowLengthPx200shaft + head
ArrowThicknessPx22shaft width
ArrowHeadSizePx56arrowhead span
ArrowOutlineThicknessPx6ink outline
PanTravelPx260pan sweep per beat
ZoomNearOffsetPx70zoom arrows, closest
ZoomFarOffsetPx220zoom arrows, farthest
BeatDurationSec1.1one sweep
BeatPauseSec0.5hold between beats
ArrowFillOpacity0.92map stays faintly readable

Pan (4-beat loop): a single arrow cycles left→right, right→left, up→down, down→up — sweeping PanTravelPx over BeatDurationSec, holding BeatPauseSec, then repeating.

Zoom (2-beat loop): a symmetric pair either side of the anchor — zoom in (start near, spread outward to ZoomFarOffsetPx) then zoom out (start far, close inward to ZoomNearOffsetPx).

Gold fill (not the coach bar's cream/leaf) so it reads as "do this". Hides the instant the real pan/zoom is registered by AdvanceCameraSteps. Beat logic is engine-free Core (GestureCoach); the arrowhead here is drawn solid for the mockup, procedurally as a chevron in-engine.
