Settings menu

An in-game settings menu: a left sidebar of tabs with a content pane, opened from a gear on the HUD. MVP tabs are About (shows the app version) and a hidden Debug tab, revealed only after tapping the version label 10× within 10s — the classic Android developer-options gesture. Debug hosts on-device toggles (first: show/hide backyard fences, #152).

Shown 1:1 at the true 1920×1200 reference. Two states: default (Debug hidden) and Debug unlocked. Field values are placeholders.

Regions

Title (Settings) · Sidebar (tab rail: About, + Debug when unlocked) · Content pane (active tab's body) · Close (top-right ✕). Entry: a gear in the HUD's top-right corner (coins chip moved inboard, to its left).

About: app name + tappable version label (also the debug-unlock target) + a small credits line.

Debug (hidden until unlocked): a list of on-device toggles/actions. First toggle Show backyard fences drives WorldBuilder.ForceFencesVisible (#152). Room for more (e.g. Add coins, #286).

Design decisions (approved)

① Entry point: a gear button in the HUD's top-right corner (furthest right), with the currency chip moved just inboard, to the gear's left. This nudges the currency-chip placement, so the HUD wireframe (#174) is flagged to reconcile — the gear takes the corner.

② Sidebar vs bottom tabs: sidebar only — the game is landscape-locked (#22/#256), so there's no portrait case to design a bottom-tab variant for.

③ Debug unlock persistence: resets each session — the Debug tab ships hidden and is re-hidden on every launch; re-tap the version 10× to reveal. (Persisting across launches is a one-flag change if you'd rather unlock once.)

Opens from a HUD gear · reuses Shared UI Components (#173) · reference resolution 1920×1200 · establishes the "debug affordances live in the Debug tab" standard (#219). Constants born here (#161); EditMode tests assert the built menu against them.
