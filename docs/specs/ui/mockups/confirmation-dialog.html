Confirmation dialog

A small, reusable centered card over a dimmed scene that asks the player to confirm one action. The title and body text are dynamic — supplied by whatever opened it — and the two actions are simple No / Yes pill buttons. First consumer: the map-expansion zone unlock (#343), shown here with placeholder copy.

Shown 1:1 at the true 1920×1200 reference. The title/body copy is a placeholder — real text is passed in by the caller.

Regions

Scrim (full-screen dim; tapping it = cancel = No) · Title (dynamic) · Body (dynamic) · Action row (two equal-width pill buttons).

Dynamic text: title and body are set by the caller; the card grows vertically with the body length. Messages are meant to be short (one question + a sentence), so no scrolling — keep copy tight.

Buttons: No = neutral/cream (left, the safe default), Yes = positive/leaf (right). The confirm tint is overridable to coral for a spend or destructive action (per the shared role-tint map); labels default to Yes/No but a caller may override (e.g. “Unlock” / “Cancel”). Both reuse the shared PillButton (#173).

Reusable: one overlay any screen can raise. First use is the zone-unlock confirm (#343, tap the lock icon → this dialog → TryUnlockNextZone()); later uses (house build/upgrade spend, etc.) reuse it by passing their own copy.
