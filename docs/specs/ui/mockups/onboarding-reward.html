Onboarding reward panel

A bespoke celebration panel raised each time the player completes an onboarding step (finish the first quest, upgrade a house, expand the map, build a house). It calls out the coin payout that today lands silently — a medal, a big “You did it!”, the reward as the hero, a coin burst, and one friendly Yay! button. One reusable panel for every onboarding step (#374), not a dialog per flow.

Shown 1:1 at the true 1920×1200 reference. The message line + amount are placeholders — the caller passes what was done and the reward (today +100). Deliberately NOT the neutral confirmation card.

Regions

Scrim (dim; tapping dismisses) · Medal (gold, overlaps top) · Coin burst (celebratory, animated on device) · Heading (fixed “You did it!”) · Message (dynamic, one line) · Reward chip (gold coin + +amount, hero) · Yay! (single leaf pill).

One panel, reused for every step: the caller passes the message + amount; heading and chrome are constant. Card grows vertically with the message. Always dismissible (button or scrim) — no soft-lock (#329). One button only: a reward is an acknowledgement, not a choice.

Payout stays in Core: the panel shows the coins the reward-chain (#316) already deposited; it never moves coins. The currency chip updates on its own.

Open for review: a brief modal celebration vs. onboarding’s otherwise non-blocking principle; and whether this same panel later becomes the reward feedback for every completed quest (#372).
