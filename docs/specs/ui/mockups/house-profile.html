House profile

Tapping a house opens its profile (#208) — the mirror of the dog profile (#177). A centered card over a dimmed scene shows the house's level (1–4), its resident dog(s) as tappable links to their own profiles, and an Upgrade entry point (#59). Content scope: option B, settled by Derek on #208.

Shown 1:1 at the true 1920×1200 reference. Representative state: a Level-2 house with two residents (parent + puppy). Field values are placeholders — real level/vacancy/residents come from the house's Core data.

Regions

Header (house thumbnail · label · level badge Lv N + N-of-4 pips) · Residents (0–3 tappable link rows) · Footer action (Upgrade) · Close (top-right ✕).

Resident link: tapping a row opens that dog's profile (#177). The dog profile's Home button is the reciprocal path back here.

Upgrade: the sole footer action — the #59 house-upgrade entry point. Shows the next cost (100 / 200 / 400) and disables into Max level at level 4. The upgrade flow's own UI is #294; a decoration-slot jump is deferred (no wireframe for that screen yet).

Data: level, vacancy, and residents read from the house's Core data (House); this page fixes layout only.
