One pop-up per household; a per-dog member-chip row appears for multi-dog move-ins.

Regions & behavior

Scrim (dim; tapping dismisses without panning) · Close ✕ (#671 — flush top-right; dismisses without panning or opening the profile) · Portrait badge (graybox silhouette, overlaps top) · Heading (fixed “Welcome to the neighborhood!”) · Name · Meta (breed · household / which house) · Member-chip row (one named chip per dog; hidden for single) · Say hi! button (single leaf pill).

✕ vs. the portrait medal (#671): the medal is centered (176 px wide → x 872–1048) and the ✕ is flush at the card's top-right (72 px → x 1298–1370), so they clear by 250 px in every variant. The medal's position does not depend on content, so this clearance is constant across single, parent+puppy and three-dog households.

Two dismiss paths, one accept. The ✕ and the scrim both call the existing Dismiss() — no pan, no profile. Say hi! is the accept: dismiss + pan + open the house profile (#604). This is why the pop-up gets a ✕ where the confirmation dialog deliberately does not — that panel's No already means cancel; Say hi! does not.

One pop-up per household — the head keeps the big portrait; the member-chip row echoes each dog. Household mix 70% single / 25% parent+puppy / 5% three-dog (expansion.md — Move-in system). The row is hidden entirely for single-dog move-ins.

Timing: the panel pops WelcomePopupDelaySeconds (1–3s, default 1.5s) after the previous panel closes, so it never stacks on the quest-resolution feedback that triggered the move-in.

Camera pan is the one non-presentational behavior: “Say hi!” dismisses and pans the camera to the new house via CameraController.FocusOn — flagged for the move-in implementation (#436) to wire alongside dismiss. Tapping the scrim dismisses without panning. Always dismissible — no soft-lock.

Portrait is graybox now; a real tinted dog-model portrait (no new art — renders the existing coat-tinted model) is a fast-follow.

Modal celebration panel on the “Candy Cottage” baseline (#65) — thick outline, hard shadow, pill button · reuses Shared UI Components (#173) and the onboarding reward panel composition · reference resolution 1920×1200. Constants named per #161; EditMode tests assert the built panel against them.
