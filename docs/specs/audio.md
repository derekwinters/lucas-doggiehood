# Audio

*Epic: [#16](https://github.com/derekwinters/lucas-doggiehood/issues/16)*

An upbeat, cozy/whimsical soundtrack matching the cozy, cheerful art style, plus playful sound effects for barks, the delivery truck, item pickups, and other interactions. ([#40](https://github.com/derekwinters/lucas-doggiehood/issues/40))

> **How the spec is changing ([#798](https://github.com/derekwinters/lucas-doggiehood/issues/798)).** This line used to describe the art style the music matches as **low-poly** → it now says **cozy, cheerful** → because the low-poly rule was retired on [#796](https://github.com/derekwinters/lucas-doggiehood/issues/796); the audio direction itself is unchanged.

No specific tracks or SFX assets exist yet — this is a direction, not a delivered asset list.

## Build checklist

- [ ] Background music track(s) in a cozy/whimsical style, looping cleanly
- [ ] SFX: dog bark, delivery truck arrival, item pickup/delivery, UI tap/confirm
- [ ] Audio can be muted independently of the rest of the app (standard mobile expectation, not separately tracked as an issue but assumed)
